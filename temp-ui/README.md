# HR Help Desk UI Comparison

Comparative evaluation of UI outputs generated by DeepSeek and GLM using the same HR Help Desk requirements.

## Objective

Compare the UI capabilities and user experience produced by DeepSeek and GLM for an HR Help Desk application.

The comparison focuses on **UI capabilities only**, not backend implementation or AI model performance.

## HR Help Desk Requirements

The UI should support:

1. **Ask HR Questions**
   - Employees can ask HR-related questions.
   - Answers are presented as coming from the Knowledge Base and Solutions Database.

2. **HR Ticketing**
   - If an answer cannot be provided, the issue can be escalated.
   - The UI should show ticket creation, classification, routing, priority, and status.

3. **Solutions**
   - Frequently raised HR issues can be converted into structured solutions.
   - Solutions can be viewed and managed through the UI.

4. **RAG Integration**
   - The UI should represent information being sourced from both the Knowledge Base and Solutions Database.
